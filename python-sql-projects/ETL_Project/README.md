# ETL Project: Kaggle → Python → SQL

## Overview
This project demonstrates an ETL pipeline:
- Extract data from Kaggle API
- Transform using Python (clean column names, handle missing values)
- Load into SQL Server
- Perform analytical queries and pivot operations

## Folder Contents
- `etl_kaggle_to_sql.py` → Python ETL script jupyter source file
- `SQLFile_ETLproj` → SQL queries for analysis
- `README.md` → Documentation
